# T-15 — Список: поиск по названию + фильтр по платформе

Срез: S2. Обязательная часть: да.

## Цель

Добавить на `/games` поиск по названию (`ILIKE` + `pg_trgm`) и фильтр по
платформе, без перезагрузки страницы (HTMX-фрагмент).

## Файлы

- `app/web/routes_games.py` — `GET /games/fragment` (query: `q`, `platform`),
  `GET /games` принимает те же query-параметры для первичного рендера
- `templates/games_list.html` — форма поиска/фильтра с `hx-get` на
  `/games/fragment`
- `templates/_games_fragment.html` — сам список, переиспользуется обоими
  роутами

## Зависимости

T-10.

## Определение готовности

- Ввод части названия в поле поиска обновляет список без перезагрузки
  страницы (HTMX, `games_title_trgm_idx` используется — не полный скан).
- Выбор платформы в фильтре сужает список до игр с этой платформой.
- Пустой результат показывает явное «ничего не найдено», а не пустую страницу.

## Оценка

45 минут.
