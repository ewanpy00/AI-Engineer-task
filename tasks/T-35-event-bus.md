# T-35 — Event bus (in-memory pub/sub)

Срез: S6. Обязательная часть: нет (доп. часть 2).

## Цель

Дать раннеру способ публиковать события о ходе обхода, а веб-слою — способ
на них подписываться для SSE (ADR-5), без внешнего брокера.

## Файлы

- `app/events.py` — реализация `EventBus`/`Event` из design §4.3:
  `publish(event)` (синхронный, не блокирует воркер), `subscribe() ->
  AsyncIterator[Event]` (своя `asyncio.Queue(maxsize=100)` на подписчика,
  стратегия drop-oldest), `recent(n=50)` — кольцевой буфер на 200 событий
  для первичной отрисовки страницы статуса

## Зависимости

T-01.

## Определение готовности

- Публикация события доходит до всех активных подписчиков.
- Медленный подписчик (не вычитывает очередь) не блокирует `publish` и не
  роняет память — старые события в его очереди вытесняются новыми
  (drop-oldest), сам bus продолжает работать для остальных подписчиков.
- `recent(50)` после нескольких `publish` возвращает последние события в
  порядке публикации.
