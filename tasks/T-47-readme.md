# T-47 — README (запуск, env, ограничения)

Срез: S8. Обязательная часть: нет, но обязательна для сдачи.

## Цель

Дать финальный артефакт, по которому можно поднять и проверить проект без
переписки с автором.

## Файлы

- `README.md` — как запустить локально (Docker/venv, `schema.sql`),
  полный список переменных окружения (сверка с `.env.example` из T-01),
  что сделано / что нет из ТЗ (со ссылкой на приоритет
  обязательная → доп.2 → доп.1), известные ограничения (нет volume под
  логи на Railway — OQ-3; нет ретрая failed-игр в тот же день, кроме
  нерешённого T-49; провайдер LLM — Gemini, не Anthropic, вопреки
  первоначальному design.md), процедура пересъезда схемы (`schema.sql`
  без миграций — ADR-3)

## Зависимости

Фактически всё содержимое проекта (пишется последним, описывает то, что
реально реализовано на момент сдачи — не весь план обязателен к выполнению).

## Определение готовности

- Человек, впервые видящий репозиторий, может по README поднять проект
  локально и открыть `/games`.
- Явно перечислено, какие срезы (S0…S7) реализованы, а какие — нет, без
  расхождений с фактическим состоянием кода на момент сдачи.
