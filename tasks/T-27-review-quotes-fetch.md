# T-27 — Metacritic client: сводки и списки отзывов

Срез: S4. Обязательная часть: да.

## Цель

Получить цитаты отзывов для ведущей платформы игры: сначала готовые подборки
по тональности, при пустом результате — fallback на список отзывов (решение
владельца).

## Файлы

- `app/clients/metacritic.py` — `get_review_summary(slug, platform_slug,
  audience) -> ReviewQuotes` (`{default, positive, negative, neutral}`),
  `list_reviews(slug, platform_slug, audience, offset=0, limit=50) ->
  list[Review]`
- `app/clients/dto.py` — `Quote` (помечен в design как **НЕДОВЕРЕННЫЙ ВВОД**),
  `Review`

## Зависимости

T-05.

## Определение готовности

- Для игры с непустыми summary-подборками `get_review_summary` возвращает
  цитаты без обращения к `list_reviews`.
- Для игры с пустыми summary-подборками (или явный тест с моком пустого
  ответа) код вызывающей стороны (T-30) может получить fallback через
  `list_reviews(limit=10)` для критиков / `limit=50` для пользователей —
  сами лимиты уже соблюдены на уровне вызова из T-30, здесь метод просто
  принимает `limit` как параметр.
- Тип `Quote` нигде в этом модуле не подставляется в строки — остаётся
  структурой данных до потребления в T-30.
