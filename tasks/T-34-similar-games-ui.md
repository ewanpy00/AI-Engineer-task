# T-34 — Блок «Похожие игры» в карточке

Срез: S5. Обязательная часть: да (OQ-4). Завершает обязательную часть ТЗ.

## Цель

Показать топ-5 похожих игр в карточке, клик по названию открывает карточку
похожей игры.

## Файлы

- `templates/game_card.html` — секция «Похожие игры»: обложка + название
  (ссылка на `/game/{slug}`) + Metascore, для каждой из ≤5 записей
- `app/web/routes_games.py` — вызов `find_similar(game_id)` (T-33) в
  `GET /game/{slug}`

## Зависимости

T-33, T-14.

## Определение готовности

- На карточке игры с похожими играми виден блок из ≤5 карточек-ссылок.
- Клик по названию похожей игры открывает её собственную карточку (обычная
  навигация браузера, не HTMX — блок не требует partial-обновления).
- Если `find_similar` вернул пустой список — блок «Похожие игры» не
  рендерится вовсе (по решению из ADR-4), а не рендерится пустым.

## Оценка

25 минут.
