# T-39 — Кнопка ручного запуска (полная версия, admin-токен)

Срез: S6. Обязательная часть: нет (доп. часть 2).

## Цель

Добавить в веб-интерфейс кнопку принудительного запуска обработки, защищённую
общим секретом (OQ-8, «дефолт принят»).

## Файлы

- `app/web/routes_admin.py` — `POST /admin/run` дорабатывается: проверка
  заголовка `X-Admin-Token` против `ADMIN_TOKEN` из конфига (T-01); 202, если
  запуск стартовал; 409, если уже идёт (advisory lock / `WorkerState.status
  == 'running'`)
- `templates/status.html` — кнопка «Запустить обработку сейчас»
  (`hx-post="/admin/run"`), токен подставляется сервером в шаблон страницы
  статуса (не хранится в JS-коде отдельно)

## Зависимости

T-23, T-37, T-01.

## Определение готовности

- Нажатие кнопки на `/status` запускает `IngestRunner.run('manual')` и сразу
  видно в ленте событий (T-38) начало нового захода.
- Запрос без корректного `X-Admin-Token` получает 401/403, заход не
  стартует.
- Повторное нажатие во время идущего захода получает 409, второй заход не
  создаётся.

35 минут.
