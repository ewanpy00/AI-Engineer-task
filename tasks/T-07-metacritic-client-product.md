# T-07 — Metacritic client: карточка продукта (product)

Срез: S1. Обязательная часть: да.

## Цель

Получать полную информацию об игре: название, описание, разработчик,
издатель, ESRB, обложка, видео, жанры, платформы + Metascore по каждой.

## Файлы

- `app/clients/metacritic.py` — `get_product(slug) -> Product`
- `app/clients/dto.py` — `Product`, `PlatformInfo` dataclasses по design §4.1,
  включая `raw: dict` (сырой ответ для `games.raw`)
- Определение ведущей платформы: `isLeadPlatform`, если поле отсутствует —
  платформа с наибольшим `metascore_count`, при равенстве — первая в массиве
  (правило зафиксировано в design §8, таблица «чего не покрыл research»)

## Зависимости

T-05.

## Определение готовности

- `get_product(slug)` для реальной игры возвращает непустые `title`,
  `platforms` (≥1), у ровно одной платформы `is_lead=True`.
- `raw` содержит сырой JSON-ответ целиком.
- Отсутствующие поля (например, нет `esrb_rating`) не роняют вызов, приходят
  как `None`.

45 минут.
