# T-38 — Страница /status + SSE /events

Срез: S6. Обязательная часть: нет (доп. часть 2).

## Цель

Дать веб-интерфейс реального времени: статусы воркера, счётчики обработанных
записей, лента событий (ADR-5).

## Файлы

- `app/web/routes_status.py` — `GET /status` (первичный рендер из
  `WorkerState` + последние `runs`), `GET /events` (`text/event-stream`,
  async-генератор поверх `EventBus.subscribe()`, keep-alive комментарий
  каждые 15 с против обрыва идле-соединения прокси Railway)
- `templates/status.html` — счётчики, текущая фаза, лента последних событий,
  `htmx-ext-sse` для обновления фрагментов без перезагрузки

## Зависимости

T-35, T-36, T-03.

## Определение готовности

- Открытие `/status` во время активного захода (T-37 генерирует события)
  показывает меняющиеся в реальном времени счётчики без перезагрузки
  страницы (обновления видно в браузере при запущенном обходе).
- Разрыв соединения браузером и повторное открытие `/status` не требует
  перезапуска сервера — SSE переподключается штатно (браузерное поведение
  `EventSource`).
- После 15+ секунд простоя между событиями соединение не обрывается прокси
  (keep-alive пинг подтверждён вручную по логам/сетевой вкладке).
