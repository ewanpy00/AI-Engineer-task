# T-41 — Поиск ролика через yt-dlp

Срез: S7. Обязательная часть: нет (доп. часть 1).

## Цель

Найти самый популярный летсплей по игре на YouTube через `yt-dlp ytsearch`
(ADR-8) — единственный проверенный путь без официального API квоты.

## Файлы

- `app/letsplay/finder.py` — реализация `LetsplayFinder` из design §4.5:
  `find(game_title) -> VideoCandidate | None`, `ytsearch` с достаточным
  числом результатов, выбор по `view_count`

## Зависимости

T-01.

## Определение готовности

- Для популярной игры метод возвращает `VideoCandidate` с `video_id`,
  `video_url`, `title`, `channel`, `view_count`.
- Пустая/неоднозначная выдача (`LOGINREQUIRED` или пусто) → `None`, а не
  исключение наружу.
- **Риск, зафиксированный в design ADR-8:** с датацентрового IP Railway
  yt-dlp может не работать вообще — проверяется фактически на этом шаге,
  не блокирует остальной сервис (letsplay — best-effort).

## Оценка

45 минут.
