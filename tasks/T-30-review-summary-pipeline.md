# T-30 — Пайплайн резюме отзывов (сборка, вызов, отказы)

Срез: S4. Обязательная часть: да.

## Цель

Соединить T-24/T-26/T-27/T-28/T-29 в одну функцию: собрать цитаты ведущей
платформы, вызвать LLM отдельно для критиков и пользователей, сохранить
результат, обработать все виды отказов без падения обхода игры.

## Файлы

- `app/llm/review_pipeline.py` — функция вида
  `summarize_game_reviews(game_id, slug, lead_platform_slug, title) -> None`
  - для каждого `audience` в `(critic, user)`:
    - `get_review_summary`, если пусто — `list_reviews` (критики `limit=10`,
      пользователи `limit=50`); если и это пусто — `status='no_data'`, LLM не
      вызывается
    - обрезка: ≤ 2000 символов на цитату, ≤ 14 цитат критиков / ≤ 20
      пользователей (design §5.3)
    - `quotes_hash` = sha256 нормализованного набора цитат; если совпадает с
      уже сохранённым в `review_summaries` — LLM не вызывается повторно
      (design §3.2, §5.6)
    - цитаты оборачиваются в `<review id="N" bucket="...">…</review>` в
      отдельном `user`-сообщении, экранируются `<`/`>`; **никогда** не идут в
      system-промпт (жёсткое правило проекта — недоверенный ввод)
    - вызов `LlmClient.summarize_reviews` (T-24), запись через `JsonlLogger`
      (T-29) после ответа
    - результат → `review_summaries` (T-28): `ok`/`llm_failed`/`no_data`
  - circuit breaker: 5 подряд неудач LLM в рамках одного захода — LLM
    отключается до конца захода, ошибка не эскалируется в `runs.status`

## Зависимости

T-24, T-26, T-27, T-28, T-29.

## Определение готовности

- Игра с непустыми отзывами получает две строки в `review_summaries`
  (`critic`, `user`) со статусом `ok`, заполненными `liked`/`disliked`/`tldr`.
- Повторный вызов пайплайна для той же игры с тем же набором цитат **не**
  порождает новый вызов LLM (проверяется по отсутствию новой строки в
  `logs/llm/*.jsonl`) — только по факту изменения набора цитат.
- Принудительный сбой LLM (мок, 5 подряд неудач) переводит соответствующие
  строки в `llm_failed` и не прерывает обработку остальных игр батча.
- Ни при каком статусе цитаты пользователей не встречаются в `system`-роли
  ни в одном сообщении, отправленном в LLM (проверяется по содержимому
  `messages` в JSONL-логе).
