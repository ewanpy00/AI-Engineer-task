# T-25 — Загрузчик промптов (PromptRepo)

Срез: S4. Обязательная часть: да.

## Цель

Промпты приложения живут в `prompts/*.md` и версионируются, в коде — только
загрузка (правило проекта, CLAUDE.md; design §5.2).

## Файлы

- `app/llm/prompts.py` — реализация `PromptRepo` из design §4.4:
  `load(name) -> Prompt` (`name`, `version`, `text`, `sha256`), парсинг
  front-matter файла `prompts/{name}.v{N}.md` (модель, `max_tokens`,
  `temperature`, описание инструмента + тело system-промпта), кэш в памяти
  на процесс

## Зависимости

T-01.

## Определение готовности

- `load("review_summary_critic")` находит `prompts/review_summary_critic.v1.md`,
  возвращает `version="v1"`, корректный `sha256` тела файла.
- Изменение файла без переименования (без изменения версии) меняет
  возвращаемый `sha256` при следующем холодном старте — используется как
  сигнал в T-30 «промпт поправили без версии».
- Отсутствие файла — понятная ошибка, а не `FileNotFoundError` без контекста.
