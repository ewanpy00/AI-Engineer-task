# T-09 — Ручной ingest без курсора (POST /admin/run минимальный)

Срез: S1. Обязательная часть: да.

## Цель

Получить сквозной путь «нажали кнопку → 20 игр в БД» без часового цикла,
claim'а и планировщика (они появятся в T-17…T-23) — чтобы как можно раньше
увидеть реальные данные и задеплоить (T-11).

## Файлы

- `app/web/routes_admin.py` — `POST /admin/run`: последовательно
  `list_new_releases(20)` → для каждой игры `get_product` → `upsert_game`
  (без claim-дедупа, без блокировки одновременных запусков — временно,
  до T-19/T-22)

## Зависимости

T-06, T-08, T-03.

## Определение готовности

- `POST /admin/run` синхронно (или с ожиданием) обрабатывает 20 игр и кладёт
  их в БД, ответ 200 с телом вида `{"processed": 20}`.
- Повторный вызов не падает (upsert идемпотентен по T-08).
- Эта ручка будет заменена на полную версию в T-22/T-23/T-39 — пометить
  `# TODO T-22` в коде.

## Оценка

40 минут.
