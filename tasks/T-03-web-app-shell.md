# T-03 — Каркас веб-приложения (FastAPI + Jinja2)

Срез: S0. Обязательная часть: да.

## Цель

Поднять FastAPI-приложение с серверным рендерингом Jinja2 без SPA (стек
зафиксирован в `11-decisions.md`), с пустой страницей списка игр.

## Файлы

- `app/main.py` — создание FastAPI-приложения, монтирование роутеров, Jinja2
- `templates/base.html` — базовый layout (без JS-фреймворков, минимальный CSS)
- `templates/games_list.html` — заглушка «игр пока нет»
- `app/web/routes_games.py` — `GET /` (редирект на `/games`), `GET /games`
  (рендер шаблона, без данных из БД)

## Зависимости

T-01.

## Определение готовности

- `GET /` отдаёт редирект на `/games`.
- `GET /games` возвращает 200 и HTML с заглушкой.
- Проект запускается одной командой (uvicorn), без сборки фронта.

30 минут.
