# T-08 — Upsert игр/платформ/жанров

Срез: S1. Обязательная часть: да.

## Цель

Записать `Product` в БД одной транзакцией: `games` + `game_platforms` +
`game_genres`, включая денормализованные `genres_cache`, `best_metascore`.

## Файлы

- `app/ingest/upsert.py` — функция `upsert_game(product: Product) -> None`
  (или возвращает `game_id`), одна транзакция на игру

## Зависимости

T-04, T-07.

## Определение готовности

- Повторный вызов с тем же `slug`/`id` обновляет запись (не создаёт дубликат),
  `updated_at` меняется.
- `genres_cache` в `games` совпадает по содержимому со строками в
  `game_genres` для той же игры.
- `best_metascore` = максимум `metascore` среди платформ игры (или `NULL`,
  если оценок нет).
- Ошибка в середине транзакции не оставляет частично записанную игру
  (проверено: рассинхрон `games`/`game_platforms` невозможен).
