# T-43 — Промпт + LLM-заключение по летсплею

Срез: S7. Обязательная часть: нет (доп. часть 1).

## Цель

Сделать короткое заключение по тексту пересказа летсплея (ТЗ: «по тексту
сделать заключение») через Gemini-адаптер (T-24), а не через Anthropic —
провайдер зафиксирован decisions.md для всех вызовов LLM.

## Файлы

- `prompts/letsplay_conclusion.v1.md` — промпт на русском
- `app/llm/gemini_client.py` — `conclude_letsplay(game_title, retelling) ->
  LlmResult[LetsplayConclusionOut]` (уже объявлено в контракте T-24,
  здесь — реализация тела метода и схемы `LetsplayConclusionOut`)

## Зависимости

T-24, T-25.

## Определение готовности

- Вызов на тестовом пересказе возвращает структурированный вывод (короткое
  заключение), а не сырой текст.
- Вызов логируется через `JsonlLogger` (T-29) так же, как резюме отзывов —
  единая точка логирования LLM, не отдельная.
- Пересказ (недоверенный ввод — расшифровка чужой речи) уходит отдельным
  `user`-сообщением, не в system-промпт, аналогично правилу T-30.
