# T-33 — SQL похожих игр

Срез: S5. Обязательная часть: да (OQ-4).

## Цель

Реализовать подбор топ-5 похожих игр из своей БД: пересечение жанров +
бонус за совпадение разработчика, без кэша, на лету (ADR-4, design §3.5).

## Файлы

- `app/similar.py` — функция `find_similar(game_id) -> list[SimilarGame]`,
  SQL-запрос ровно по `docs/10-design.md` §3.5 (вес разработчика = +2)

## Зависимости

T-08, T-04.

## Определение готовности

- Для игры с ≥1 жанром и хотя бы одной другой игрой того же жанра в БД
  возвращается непустой список (≤5), отсортированный по `score DESC,
  best_metascore DESC NULLS LAST, title`.
- Для игры без жанров вообще (`game_genres` пуст) возвращается пустой список,
  не ошибка.
- Игра, совпадающая только по разработчику (без общих жанров), в выдачу не
  попадает — запрос требует хотя бы один общий жанр (INNER JOIN по `genre`).
