# T-32 — Подключение резюме отзывов к ingest runner

Срез: S4. Обязательная часть: да.

## Цель

Вызывать пайплайн резюме отзывов (T-30) для каждой игры внутри
`IngestRunner.process_game` (T-22), не давая отказу LLM ронять обход
каталога (design §5.5: «отказ LLM никогда не роняет обход каталога»).

## Файлы

- `app/ingest/runner.py` — в `process_game`: после успешного upsert игры
  (T-08/T-13) — вызов `summarize_game_reviews(...)`, обёрнутый так, чтобы
  любое необработанное исключение внутри пайплайна логировалось и не меняло
  `processed_games.status` игры (сама игра уже `ok` по данным каталога)

## Зависимости

T-30, T-22.

## Определение готовности

- Ручной заход (`POST /admin/run`) на реальных данных кладёт строки в
  `review_summaries` для каждой обработанной игры без явного отдельного
  вызова пайплайна разработчиком.
- Отключённый/сломанный ключ Gemini (проверяется подстановкой неверного
  `GOOGLE_API_KEY`) не мешает игре получить `processed_games.status='ok'`
  по каталожным данным — резюме останется `llm_failed`, обход не падает.

## Оценка

25 минут.
