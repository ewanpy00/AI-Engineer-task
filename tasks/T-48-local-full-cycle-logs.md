# T-48 — Локальный полный часовой прогон + сбор logs/llm/*.jsonl

Срез: S8. Обязательная часть: да (evidence для правила проекта о логах).

## Цель

Предъявить реальные raw JSONL-логи LLM-вызовов, как того требует правило
проекта («Все обращения к LLM из кода приложения логируются в
`logs/llm/*.jsonl`»). По решению владельца (OQ-3) Railway-volume не
покупается, поэтому логи для сдачи собираются локальным прогоном, а не с
прод-инстанса.

## Файлы

Не создаёт новый код. Артефакт — сами файлы `logs/llm/{YYYY-MM-DD}.jsonl`,
приложенные к сдаче (в архиве/репозитории — по решению о том, коммитятся ли
логи; если нет — прикладываются отдельно).

## Зависимости

T-32 (резюме отзывов работает end-to-end). Желательно выполнять после T-45,
если доп. часть 1 успела быть сделана — тогда в логах будет и
`letsplay_conclusion`, а не только резюме отзывов.

## Определение готовности

- Локальный запуск приложения выполнил хотя бы один полный заход обхода
  (ручной запуск через `/admin/run` — достаточно, часовое ожидание
  планировщика не обязательно) на ≥ 5 играх.
- `logs/llm/{дата}.jsonl` содержит записи и для `review_summary_critic`, и
  для `review_summary_user`, каждая — валидный JSON со всеми полями из
  design §5.4.
- Если доп. часть 1 реализована — в логе также есть записи
  `letsplay_conclusion`.
