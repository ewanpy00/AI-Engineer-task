# T-16 — Список: сортировка по рейтингу + пагинация

Срез: S2. Обязательная часть: да.

## Цель

Добавить сортировку списка игр (`sort=metascore|userscore|new`) и постраничную
навигацию, используя те же HTMX-фрагменты, что и T-15.

## Файлы

- `app/web/routes_games.py` — параметры `sort`, `page` в `GET /games` и
  `GET /games/fragment`, использует индексы `games_best_metascore_idx`,
  `games_best_userscore_idx`, `games_first_seen_idx`
- `templates/games_list.html` — переключатели сортировки, ссылки пагинации

## Зависимости

T-10.

## Определение готовности

- `sort=metascore` и `sort=userscore` дают убывающий порядок соответствующего
  поля, `NULL` — в конце.
- `sort=new` сортирует по `first_seen_at DESC` (поведение по умолчанию).
- Постраничная навигация не ломает одновременно применённые `q`/`platform`
  из T-15 (параметры сохраняются в ссылках пагинации).
