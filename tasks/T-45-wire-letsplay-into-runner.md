# T-45 — Подключение летсплея к ingest runner

Срез: S7. Обязательная часть: нет (доп. часть 1).

## Цель

Вызывать `LetsplayPipeline.enrich` для каждой игры внутри
`IngestRunner.process_game`, не влияя на статус самой игры при отказе фичи.

## Файлы

- `app/ingest/runner.py` — в `process_game`: после резюме отзывов (T-32) —
  вызов `letsplay_pipeline.enrich(game_id, title)`; событие `letsplay` в
  `EventBus` (T-35/T-37), если мониторинг уже реализован на момент этой
  задачи

## Зависимости

T-44, T-22.

## Определение готовности

- Ручной заход кладёт строку в `letsplays` для каждой обработанной игры.
- Полное отключение 300.ya.ru (неверный `YA300_SESSION_ID`) не меняет
  `processed_games.status` игр — они остаются `ok` по каталожным данным.

## Оценка

25 минут.
