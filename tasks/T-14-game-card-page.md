# T-14 — Карточка игры — полная страница

Срез: S2. Обязательная часть: да.

## Цель

Реализовать `GET /game/{slug}` — полную информацию по игре, кроме резюме
отзывов (T-31), похожих игр (T-34) и летсплея (T-46), которые довешиваются
на эту же страницу позже отдельными блоками.

## Файлы

- `app/web/routes_games.py` — `GET /game/{slug}`
- `templates/game_card.html` — название, обложка, описание, разработчик,
  издатель, ESRB, таблица платформ (Metascore + Userscore на платформу),
  видео (embed по `video_url`)

## Зависимости

T-13, T-03.

## Определение готовности

- Открытие `/game/{slug}` для реальной игры показывает все поля из ТЗ п.
  «Информация, которую забираем», кроме резюме/похожих/летсплея.
- Несуществующий `slug` → 404.
- Разметка карточки содержит именованные секции (`id`/`data-`) под блоки
  T-31, T-34, T-46, чтобы их можно было добавить без переверстки всей страницы.

## Оценка

45 минут.
