# T-10 — Список игр — базовый UI

Срез: S1. Обязательная часть: да.

## Цель

Показать реальные игры из БД на странице `/games`: краткая информация по
каждой (название, обложка, платформы, Metascore).

## Файлы

- `app/web/routes_games.py` — `GET /games` читает список игр из БД
  (сортировка по умолчанию — `first_seen_at DESC`)
- `templates/games_list.html` — карточка-превью на игру: обложка (через CDN
  Metacritic по `cover_path`), название, список платформ, Metascore

## Зависимости

T-08, T-03.

## Определение готовности

- После `POST /admin/run` (T-09) страница `/games` показывает 20 игр с
  обложками, названиями и Metascore.
- Обложка отдаётся напрямую с CDN Metacritic (без прокси/скачивания —
  по решению владельца).
