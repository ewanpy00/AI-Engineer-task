# T-05 — Metacritic client: ядро (rate-limit, retry, UA, ошибки)

Срез: S1. Обязательная часть: да.

## Цель

Собрать общий HTTP-слой клиента `backend.metacritic.com`: единая точка на
которую опираются все остальные методы клиента (T-06, T-07, T-12, T-27).

## Файлы

- `app/clients/metacritic.py` — базовый класс/функция запроса: httpx
  `AsyncClient`, явный не-дефолтный User-Agent, клиентский rate-limit ≤ 1 rps
  (глобальный, не per-эндпоинт), retry/backoff на 429/5xx/таймаут,
  `MetacriticError(status, url, body_excerpt)` как единственное исключение
  наружу

## Зависимости

T-01.

## Определение готовности

- Юнит-тест (или ручная проверка) на моках httpx: 2 последовательных запроса
  разнесены по времени не менее ~1 секунды.
- 500-й ответ ретраится согласно backoff, после исчерпания попыток наружу
  летит `MetacriticError`, а не сырое исключение httpx.
- Модуль не содержит логики маппинга под конкретные эндпоинты — это T-06/T-07.

## Оценка

50 минут.
