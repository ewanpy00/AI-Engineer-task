Обязательная часть

Реализовать сервис, который 1 раз в час заходит на Metacritic в раздел Games берет новые 20 игр, которые сегодня не обрабатывал и добавляет информацию о них в свою базу или обновляет её если игра уже есть в базе.

Выборка игр:
Первые 20 игр берем со страницы Games https://www.metacritic.com/game/ - раздел New Releases
При последующих обработках берем игры из раздела SEE ALL (сортировка Новые)  - https://www.metacritic.com/browse/game/all/all/all-time/new/ - можно за каждый заход обрабатывать очередную страницу с играми.
Каждый новый день начинаем выбирать заново – сначала игры из пункта 1, затем из 2.

Информация, которую забираем:
Название игры
Картинка-обложка
Платформа + Metascore + Userscore (платформ может быть много ps5, ns2 и т.д.)
Разработчик
Описание
Ссылку на видео

Просматривает отзывы и пишет короткое резюме, что игрокам нравится в игре, что нет. Резюме по отзывам делает отдельно для отзывов критиков, отдельно по отзывам пользователей. Эта часть информации может обновлятся при повторных обходах.

В сервисе сделать веб-интерфейс:
Список загруженных игр (краткая информация по каждой игре)
Карточка игры – полная информация, перечислена выше
Фильтр по платформам
Поиск по названию игры
Сортировка по рейтингу

Для каждой игры подобрать похожие игры из тех что уже есть в базе сервиса и отображать их в карточке игры. Клик по имени открывает карточку этой игры.

Для каждой игры поискать летсплеи на YouTube, взять самый популярный летсплей и перевести рассказ блоггера в текст, далее по тексту сделать заключение и добавить его к информации об игре со ссылкой на ролик.


Добавить, real time monitoring в веб-интерфейсе можно было мониторить процесс работы сервиса в реальном времени (статусы воркеров, количество обработанных записей и т.п.). 

И добавить кнопку принудительного запуска процесса обработки.
